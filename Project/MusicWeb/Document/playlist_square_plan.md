# 歌单广场功能开发计划

> **文档版本**: v1.0  
> **创建日期**: 2026-02-06  
> **状态**: 待开发

---

## 一、背景与目标

### 1.1 现状问题

| 问题 | 描述 |
|------|------|
| 榜单同质化 | 热歌榜与收藏榜数据高度重叠（均基于收藏数排序） |
| 收藏入口冗余 | "我的收藏"导航可由默认歌单"我喜欢的音乐"替代 |
| 歌单资源匮乏 | 本地数据库仅3个歌单，无法支撑歌单发现场景 |

### 1.2 目标

1. **替换"我的收藏"导航** → "歌单广场"
2. **接入网易云歌单API**，为用户提供丰富的歌单推荐
3. **统一收藏逻辑**，收藏操作写入默认歌单

---

## 二、技术方案

### 2.1 数据来源

采用 MusicServer 已封装的网易云音乐API：

| 接口 | 路径 | 用途 |
|------|------|------|
| 推荐歌单 | `/personalized` | 获取个性化推荐歌单列表 |
| 歌单分类 | `/top/playlist` | 按分类获取歌单 |
| 歌单详情 | `/playlist/detail` | 获取歌单基本信息 |
| 歌单歌曲 | `/playlist/track/all` | 获取歌单完整歌曲列表 |

### 2.2 架构设计

```
用户浏览器
    ↓
playlist_square.jsp (前端页面)
    ↓ AJAX
PlaylistSquareServlet (后端)
    ↓ HTTP
MusicServer (Node.js, localhost:3000)
    ↓
网易云音乐 API
```

## 三、实施内容

### 3.1 新增文件

| 类型 | 路径 | 描述 |
|------|------|------|
| Servlet | `com.music.servlet.PlaylistSquareServlet` | 歌单广场后端接口 |
| JSP | `webapp/playlist_square.jsp` | 歌单广场页面 |

### 3.2 修改文件

| 文件 | 改动内容 |
|------|----------|
| `user.jsp` | 导航栏 "我的收藏" → "歌单广场" |
| `FavoriteServlet.java` | 收藏操作改为写入默认歌单 |

### 3.3 收藏系统迁移

1. 执行数据迁移脚本：`favorites` 表数据 → 默认歌单
2. 修改收藏逻辑：❤️ 操作写入 `playlist_songs` 表
3. 保留 `favorites` 表备份
