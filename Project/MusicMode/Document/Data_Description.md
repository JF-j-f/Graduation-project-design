# 数据集详细说明

这个数据集主要由 **交互数据**、**歌曲元数据** 和 **用户画像** 三部分组成：

## A. 交互行为数据（推荐系统的核心）

### `train.csv` (约 948 MB, ~737 万行)
- **含义**：训练集，记录了用户在一段时间内的听歌历史。[1][2][3][4][5][6]
- **主要字段**：
    - `msno`: 用户 ID（已脱敏）。[1][2][4]
    - `song_id`: 歌曲 ID。
    - `source_system_tab`: 用户是从哪个页面进入的（例如：我的库、搜索、发现）。[4][7]
    - `source_screen_name`: 用户看到的界面名称。
    - `source_type`: 播放入口类型（例如：专辑、在线歌单、单曲）。[4]
    - `target` (目标变量): 1 表示用户在第一次听完后一个月内有重复收听行为；0 表示没有。这是你的模型需要预测的值。[2][4]

### `test.csv` (约 339 MB, ~255 万行)
- **含义**：测试集，用于验证模型预测效果。除了没有 `target` 列外，结构与 `train.csv` 一致。

## B. 歌曲信息（用于基于内容的推荐）

### `songs.csv` (约 216 MB, ~229 万条歌曲)
- **主要字段**：
    - `song_id`: 唯一标识。[4]
    - `song_length`: 歌曲时长（毫秒）。
    - `genre_ids`: 流派 ID（可能一首歌有多个流派，用 `|` 分隔）。
    - `artist_name`: 歌手名。
    - `composer`: 作曲家。[3][5][7]
    - `lyricist`: 作词家。[5]
    - `language`: 语言代码。

### `song_extra_info.csv` (约 176 MB, ~229 万条)
- **主要字段**：
    - `song_id`: 唯一标识。[4]
    - `name`: 歌曲名字。
    - `isrc`: 国际标准录音制品编码（通过这个编码可以挖掘出歌曲的发行国家和年份）。[4]

## C. 用户信息（用于用户画像）

### `members.csv` (约 2.4 MB, ~3.4 万个用户)
- **主要字段**：
    - `msno`: 用户 ID。[1][2][4]
    - `city`: 城市代码。
    - `bd`: 年龄（注意：此列包含很多 0 或异常值，需要清洗）。
    - `gender`: 性别。[7]
    - `registered_via`: 注册渠道。[1][2]
    - `registration_init_time`: 首次注册时间。
    - `expiration_date`: 会员到期时间。
